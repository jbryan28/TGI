# Daily Zone Command sibling site

This brand layer mirrors the maintained TraderGrowth website for DailyZoneCommand.com. The parent site and its CNAME remain unchanged. Daily Zone Command is the method, book, and course; Jay’s Daily Zones remains the $99/month membership. The TGI company attribution, existing checkout, newsletter form, Calendly event, contact details, legal text, member charts, and GIF remain intact.

Run `node scripts/build-dzc.mjs /absolute/empty/output` to prepare the static site. The default output is `dzc-preview/`, which is ignored by Git. The output excludes source specifications, tests, credentials, Git metadata, and CNAME.

The DZC hero groups the headline on the left and supporting copy, CTAs, and trust note on the right. At 900px and below, the supporting content stacks after the headline in reading order.

The DZC document clips horizontal overflow and contains sideways overscroll. Mobile header columns and homepage grid children can shrink to the screen width, while the existing slider rails keep their own horizontal scrolling and touch controls. The founder section reads “Why Jay started DZC” with matching introductory copy.
