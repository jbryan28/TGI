# TGI email brand assets

Permanent production URLs:

- BIMI logo: `https://www.tradergrowth.com/assets/bimi/tgi-logo.svg`
- Reserved mark certificate: `https://www.tradergrowth.com/assets/bimi/tgi-mark-certificate.pem`

The SVG is an SVG Tiny PS asset with fixed 96-pixel dimensions, a square view box, and a solid background for Gmail compatibility.

Do not add a placeholder at the certificate URL. Add `tgi-mark-certificate.pem` only after a certificate authority issues the final CMC or VMC bundle. Publishing invented or incomplete certificate material would invalidate BIMI verification.
